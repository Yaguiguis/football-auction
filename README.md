# Football Auction

Jogo web de leilão de futebol para jogar com amigos por código de sala.

A primeira versão está sendo construída em Next.js, com multiplayer planejado via Supabase Realtime e deploy na Vercel.

## Funcionalidades planejadas

- Salas privadas por código
- Futebol de campo e futsal
- Orçamento configurável
- Leilão em tempo real
- Regra QUERO/PASSAR
- Jogador grátis quando somente um participante quiser
- Formações como 4-3-3 e 4-4-2
- Banco com 2 reservas
- Simulação final dos elencos
- Tema preto, branco e vermelho
